# Phase 3 — Art, Motion, and Sound Pass

## Goal

Turn the complete placeholder game into a polished night-market experience.

Do not start this phase until:

1. Phase 2 has passed playtest.
2. Mood board / Figma direction is locked.
3. Asset direction is available.

## Creative role

Claude Code should use this phase to apply the final visual system, motion polish, flame rendering, and sound direction. Codex should only help here if asked for technical refactors or performance fixes.

## Core art direction

Late-night Malaysian street food market:

- deep indigo / near-black sky
- tungsten bulbs
- warm stall light
- wet pavement reflections
- steam layers
- neon signage, but warm and local rather than cyberpunk
- crowded but readable silhouettes

The flame is the visual signature. It should feel satisfying every time the player pinches.

## Replace placeholders

Replace Phase 1–2 geometry with final visuals for:

- chef on wok
- burner flame
- zappers / electrified stall wires / signs
- scooter/motorbike missiles
- steam vents
- ingredients
- satay cart
- kuih carrier
- teh tarik pull
- shoppers
- parallax market backgrounds
- HUD
- webcam PIP label/styling
- recipe wheel

## Motion priorities

- Burner ignition response on pinch.
- Flame grows and breathes while held.
- Release has a clean flame-out.
- Tumble/slide should feel physical and satisfying.
- Ingredient collection needs small sparkle/juice.
- Vehicle pickup should briefly slow time and feel celebratory.
- Mission and rank banners should feel rewarding without blocking play.
- Milestones should flash confidently but not obscure obstacles.

## Sound direction

Create an environment, not just a soundtrack.

Base ambience:

- sizzling food
- distant chatter
- plates/clatter
- occasional motorbike horn
- small radio/music texture

Effects:

- gas ignition
- sustained burner hiss
- flame off
- ingredient chime
- scooter warning/pass
- zapper crackle
- steam hiss
- vehicle pickup
- vehicle destroyed
- death thud/wok clatter
- slide scrape
- wheel spin clicks
- prize stinger
- mission complete
- rank up

## Creative anti-patterns

Do not introduce:

- sci-fi lab language
- dark serious survival-game tone
- neon synthwave
- chibi/cute mascot style
- generic “Asian” symbols
- store/microtransaction UI
- cluttered HUD

## Phase 3 exit criteria

- The game still runs smoothly.
- Gameplay readability is not reduced by art.
- Flame feels iconic and responsive.
- The night market world is specific, warm, and alive.
- HUD and overlays clearly communicate the game state.
- Sound supports input feedback and environment without becoming annoying.
